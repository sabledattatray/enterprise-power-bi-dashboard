## Core Brand Palette

| Token | Name | Hex | HSL | Power BI Theme Role |
|---|---|---|---|---|
| Primary | Royal Fabric Blue | `#2563EB` | `hsl(221, 83%, 53%)` | Primary KPI highlights, active bars, key lines |
| Navy | Deep Enterprise Navy | `#172554` | `hsl(226, 71%, 21%)` | Navigation bar background, high-contrast headers |
| Accent Teal | Enterprise Teal | `#0D9488` | `hsl(175, 84%, 32%)` | Secondary trends, delivered status, forecast bands |
| Accent Green | Success Green | `#16A34A` | `hsl(142, 76%, 36%)` | Positive variance, profit margin growth, on-time delivery |
| Accent Amber | Warning Amber | `#F59E0B` | `hsl(38, 92%, 50%)` | Return rates, processing status, threshold alerts |
