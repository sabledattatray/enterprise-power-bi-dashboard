# Professional SVG Icon Library

This directory contains a curated library of **62 vector SVG icons** designed for modern Microsoft Power BI dashboards. Every icon has been formatted for crisp display on high-DPI displays, standard 16:9 canvas resolutions, and mobile layouts.

---

## Icon Characteristics

- **Format:** Clean XML SVG (Scalable Vector Graphics).
- **Transparency:** 100% transparent backgrounds for seamless card integration.
- **ViewBox:** Standardized `0 0 24 24` or calibrated vector canvas.
- **Security Audit:** Zero embedded scripts, zero foreign objects, zero external network dependencies.
- **GitHub Rendering:** Tested and verified for direct markdown preview rendering.

## Total Vector Assets: 81 Icons

### How to Use SVG Icons in Power BI

1. **Direct Image Visual:**
   - In Power BI Desktop, click **Insert > Image** and select the desired `.svg` file.
   - Set image scaling to **Fit** or **Normal** to preserve aspect ratio.

2. **DAX SVG Data URIs:**
   - Encode SVG XML as base64 or URL-encoded strings inside DAX measures:
   ```dax
   Icon_Dollar = "data:image/svg+xml;utf8,<svg ...></svg>"
   ```
   - Categorize the measure as **Image URL** under Data Category.
   - Insert into standard Table or Matrix visuals.

3. **Button & Bookmark Icons:**
   - Use in navigation sidebars for page-switching actions (Home, Sales, Products, Customers, Regions, Orders, Profitability, Returns, Forecast).
