# Security Policy

## Supported Versions

This is an open educational portfolio repository. Ongoing security updates are provided on the latest version of the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

Security issues, accidental exposure of non-synthetic private data, or credential vulnerabilities should be reported directly to the author rather than opened as public GitHub issues.

To report a vulnerability:
1. Email: **info@dattasable.com** with the subject line `[SECURITY] Enterprise Power BI Repository`.
2. Provide details of the finding, affected files, and steps to reproduce.
3. We will acknowledge receipt within 48 hours and work on remediation promptly.

---

## Data Privacy & Synthetic Information Guarantee

- **No Real Customer Data:** All customer names (`Customer 000001`, etc.), transaction values, and geographical combinations are synthetically generated for demonstration.
- **No Embedded Credentials:** No API keys, database connection strings, passwords, or tenant secrets are committed to this repository.
- **Safe Assets:** All SVG files have been audited to ensure they contain pure vector paths without embedded JavaScript, external network calls, or malicious macros.
